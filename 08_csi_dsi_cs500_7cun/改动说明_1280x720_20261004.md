# 改动说明 —— 全链路 1280x720@30Hz 改造

日期:2026-10-04 | 基线:git v1(1080p20 合并版) | 状态:代码完成,待编译上板验证

## 目标与结果

把 摄像头 → ISP → 显示/网口 全链路从 1920x1080@20fps 改为 **1280x720@约30fps**。

关键设计决策:**传感器侧 1:1 中心窗口裁剪**(不是缩放)。原因:帧率 = PCLK/(HTS×VTS),
VTS 不能小于采窗行数——1080p 采窗 1087 行配 VTS≥1087 最高只能约 20fps;只有把采窗
缩到 727 行才能用 VTS=760 达到 29.7fps。1:1 无缩放也是传感器最简单、最可靠的配置。

## 传感器寄存器改动(uics500_cfg/uics500reg.v)

| 寄存器 | 原值 | 新值 | 含义 |
|---|---|---|---|
| 0x3200/01 | 0x0154(340) | 0x0294(660) | 采窗 x 起点(在原采窗内水平居中) |
| 0x3202/03 | 0x01b4(436) | 0x0268(616) | 采窗 y 起点(垂直居中) |
| 0x3204/05 | 0x08db(2267) | 0x079b(1947) | 采窗 x 终点(窗宽 1287=1280+7) |
| 0x3206/07 | 0x05f3(1523) | 0x053f(1343) | 采窗 y 终点(窗高 727=720+7) |
| 0x3208/09 | 0x0780(1920) | 0x0500(1280) | 输出宽度 |
| 0x320a/0b | 0x0438(1080) | 0x02d0(720) | 输出高度 |
| 0x320e/0f | 0x0467(1127) | 0x02f8(760) | VTS,帧率 64.3M/(2852×760)=**29.7fps** |

- HTS(0x320c/d=2852)不变 → 每行时序不变,**MIPI 通道速率不变(~321Mbps/lane),
  DPHY RX 配置与 S_csi_rx_clk 均无需改动**。
- 窗口中心与原 1080p 采窗中心重合(1303.5, 979.5),已调好的对焦/构图不变。
- 视场变为原 1080p 画面的中心 2/3(1280/1920、720/1080),像素 1:1 无插值。
- 依据:0x3208/a=输出尺寸的语义由两个已知可用配置交叉证实(1920x1080 本工程、
  1024x600 见 lab_ex_SC500_720P 例程);资料包 04_MLK-CAM001-CS500 内
  SmartSens 官方 ini(1280x1024@60) 证明该传感器支持更多模式。**无数据手册,
  上板后先看串口 f 是否≈30、PC 是否出图,异常则回退(git checkout v1 -- . )。**
- 副作用:VTS 变小 → 最长曝光时间缩短约 1/3,极暗光下 AE 上限变低(本工程为按键
  手动 AE,正常光照无影响)。

## FPGA 链路参数改动

| 文件 | 改动 |
|---|---|
| image_correction.v | 定窗 1024x600 → **1280x720 全直通**(H≤319 拍/V≤719 行/tlast@319);顺带修复了 v1 遗留的"1024x600 裁剪 vs 1920x1080 ISP"不一致问题 |
| design_top_wrapper.v | uial2axis 1920x1080 → 1280x720 |
| isp/isp_top.v | demosaic、awb 参数 1920x1080 → 1280x720(行缓冲折行 = 1280/4 = 320 拍) |
| rgb_frame_crop.v(新增) | ISP 1280x720 → 居中 1024x600,插在 ISP 与 video_in 之间,保住 7 寸 1024x600 DSI 屏(屏物理分辨率固定,无法直显 720p 全幅);网口通路不经过它,取全幅 |
| design_top_wrapper.v | cvp_eth_dbg:IMG 1280x720,**FRAME_SKIP=1(每帧都发,30fps)** |

## 网口侧

- 1280x720x3 = 2764800 B/帧 ÷ 1440 = **1920 包/帧(整除,正是网络模块最初 720p 设计点)**
- 30fps 线速率 ≈ 1920×1512B×30 ≈ **700Mbps**,千兆内偏满;若 PC 端出现黑块/缺包,
  把 FRAME_SKIP 改 2(15fps,约 350Mbps)。
- PC 收图命令参数变化:`python eth_video_rx.py --width 1280 --height 720`

## 验证步骤(上板)

1. TD 重新编译下载(注意先关闭旧 TD 实例再开工程);
2. 串口 J3 115200 看 `CAM t=... f=..`:**f≈29~30 为传感器配置成功**(f=0 或乱跳 → 回退寄存器表);
3. PC 设 192.168.1.100/24 关防火墙,`python eth_video_rx.py --width 1280 --height 720` 看实时画面;
4. DSI 屏应显示 720p 画面的居中 1024x600 区域。
