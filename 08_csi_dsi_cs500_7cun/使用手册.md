# 使用手册 — MLKPAI-F02 相机（v23 定版）

## 1. 硬件与网络

- 板卡：MLKPAI-F02（PH1P FPGA）+ MLK-CAM001-CS500 摄像头模组 + YT8531 千兆 PHY
- 显示：7 寸 DSI 屏（1024x600，板端显示支路自动居中裁剪，无需配置）
- 网络：**PC 网卡固定 IP `192.168.1.100/24`**，板卡 `192.168.1.66`，直连或同交换机
- 防火墙：放行 UDP 6000（视频）与 6001（命令）
- 上电即推流，无需在 PC 端发起任何请求

## 2. 启动与观看

双击 `tools\打开收图窗口.bat`，或：

```
cd tools
python cam_gui.py
```

GUI 功能：
- 视频窗：1280x720@30fps，状态栏显示 fps / complete%（帧完整度，正常=100%）
- **曝光码滑条**：62..1800 半行，拖动停止 250ms 后自动下发，约 2 帧生效
- **白平衡增益 R/G/B**：Q8（256=1.0x），滑条范围 64..511（0.25x..2x）
- **R/B 通道互换**：色序错乱时使用
- **白平衡模式**：「自动」= 标定增益+1.5x 补光（推荐）；「色温 K」= 拖 2500K..10000K
  实时换算 R/B 增益（注意 K 模式无补光，画面会略暗）
- 按键：`s` 存当前帧 PNG，`q`/`ESC` 退出

## 3. 命令集（UDP 6001，可供二次开发）

包格式（12 字节）：`C5 A5 50 01` + 命令码(1B) + 值(3B 大端)，发往 `192.168.1.255:6001` 广播。

| 命令码 | 含义 | 值域 | 备注 |
|---|---|---|---|
| 1 | 曝光码 | 62..1800 半行 | 固件钳位 1800（更高会触发传感器读出窗偏移→顶/底错位带） |
| 2/3/4 | 白平衡 R/G/B 增益 | 64..511 (Q8) | 256=1.0x |
| 5 | R/B 互换 | 0/1 | |
| 6 | 白平衡模式 | 1=自动 / 0=手动冻结 | 自动时 2/3/4 与 7 失效 |
| 7 | 色温 | 25..100（=2500K..10000K） | 仅手动冻结模式生效 |

命令行示例：

```
python cam_ctrl.py exp 1700            # 曝光
python cam_ctrl.py gain 438 386 371    # 白平衡三通道
```

## 4. 调亮/调色指南（按优先级）

1. **补光**：画质无损的唯一根治手段，暗光下任何增益都有噪声代价。
2. **曝光滑条**：拉到 1800 封顶（约 30ms，已到安全上限）。
3. **GUI 白平衡增益**：手动冻结模式下三通道拉到 511（2x）——纯数字增益，即拖即生效。
4. **模拟增益档（需重编译）**：改 `isp2/cvp_proc.v` 的 `AE_GAIN_IDX`：
   `96=6.0x, 108=7.5x(默认), 112=8.0x, 128=12x, 143=15.75x(顶)`，改完 TD 重编译烧录。
   模拟增益噪声优于数字增益，优先用它。
5. **校色**：偏色用白平衡增益修（对着白纸调 R/B 至不偏色），不要动模拟增益档——
   它三通道同放，只改变亮度不改变色彩。

## 5. 诊断工具（tools/）

| 工具 | 用途 | 用法 |
|---|---|---|
| `cam_gui.py` | GUI 收图+控制 | 日常使用 |
| `capture_now.py` | 无头抓帧 4s，输出帧完整度/通道统计/存图 | **必须先关 GUI**（独占 6000） |
| `exp_sweep_test.py` | 曝光 1940→1400 逐档扫描，自动检测顶/底错位带，结束停在最亮干净档 | **必须先关 GUI**；相机静止 |
| `cam_ctrl.py` | 命令行控制 | 见上节 |
| `sim_v10.py` | 网口打包链路 Python 逐拍模拟器（曾抓出 3 次 RTL bug，改网口链路前先跑它） | 参考 |
| `tb_cmd_rx.v` | cvp_cmd_rx 的 Verilog TB | 参考 |

串口统计（板卡 UART）：`CAM` 行=传感器 RAW 层，`ISP` 行=color_correct 前。
判定基准：f=30，p/f=230400 组/帧。CAM 正常而 ISP 异常→ISP 链路问题；
CAM 异常→采集/传感器配置问题。

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 画面偏暗/偏灰 | 弱光欠曝（增益已拉满时的物理极限） | 按第 4 节顺序调；根治=补光 |
| 画面顶部或底部有一条错位带 | 曝光贴近满帧，传感器读出窗偏移 | 曝光滑条降到 1800 以下；跑 exp_sweep_test 找阈值 |
| GUI 显示 fps 很低 / complete=50% | 测量假象：6000 端口被 GUI 与脚本分流 | 抓帧测量前关掉其它收图程序 |
| 画面上下半帧缓慢互换 | （v22b 已修）uial2axis 帧高参数错 | 确认固件 ≥v22b |
| 颜色整体错乱（红蓝互换/彩噪） | 色序或 BGGR 相位 | GUI 勾「R/B 互换」；仍异常查 demosaic 相位注释 |
| 编译后黑盒/信号无驱动 | TD 自动排除出错源文件并回写 .al | 修代码后 grep `.al` 中新增的 AutoExcluded 并清除 |
| 改了源码不生效 | 新文件没加进 .al | TD 里 Add Sources，或手改 .al |

## 7. 固件编译烧录（TD）

1. 打开 `td_project/camera_to_dsi_display.al`
2. 编译前确认 `.al` 无**新增** AutoExcluded（存量 4 处为有意排除）
3. 综合→布局布线→生成比特流，产物在 `td_project/camera_to_dsi_display_Runs/`
4. 烧录 `_Runs/best_result` 中的比特流
5. 上电后约 1s 出图；传感器配置完成后曝光/增益自动写入（无需手动初始化）
