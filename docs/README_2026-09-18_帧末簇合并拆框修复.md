## 一、任务与方案演变（重要决策记录）

**任务**：确保一个完整的白细胞不会被识别成两个框（分叶核拆框）。

1. **初选方案：形态学闭运算硬件化**（用户批准方向）。先做离线核尺寸标定
   （`close_sweep.py`，K=5/9/11/13/15，MORPH_RECT）——**结果否决了该方案**：
   - K≤9：拆框与环形核均不合并（核叶间隙 > 核尺寸）；
   - K=13~15：能合并部分拆框，但 **175724 的真实大单核被误杀**（闭运算把
     其掩码与邻近杂质连成大而稀疏的组件，紧凑度过滤丢弃）；
   - **181747 环形核在任何 K 下都救不回**：定点调试（`debug_ring.py`）发现
     它是**单个已连通的 43630px 组件**（非碎裂），失败纯因稀疏（填充率 35%
     < 45%），闭运算只增面积不增填充率。
2. **改选方案：帧末簇合并**（帧末解析域，逐像素通路零改动）：外接框扩
   MERGE_GAP 后相交的组件合并成簇再选框；簇像素和过 MIN_AREA（顺带救回
   单叶不足面积的核）；紧凑度增加"分件填充率"支路（环形/花斑簇靠它过）。
3. **标定迭代中的第二个坑**：碎屑吸收稀释。v1 允许种子吸收相交碎块，
   181408 两个边界填充率（45%/51%）的真细胞因吸收相交的稀疏 RBC 碎块
   被拉低填充率误杀（6→4 框，`debug_181408.py` 实证）→ 改为
   **种子-only 语义**：不足 SEED_MIN 的组件完全不参与合并（不发起、不被并），
   簇统计只累计种子 → 对杂质免疫，全部掉框恢复。

## 八、181033 大量误检的定量根因（2026-09-18 补充）

对照测量（`debug_181033*.py`，同为 4160×3120）：

| 指标 | 181033（晚间批，8 RBC 误检） | 121635_HDR（正常批，零误检） |
|---|---|---|
| RBC 主体 H 中位 | 134（窗内） | 145（窗内）——色相不是判别维度 |
| **RBC 主体 S 中位** | **33** | **10** |
| RBC 像素落入白细胞窗（H 窗且 S≥60）比例 | **14.6%（87 万像素）** | **1.0%** |
| 误检簇内窗内像素占比 | 29%~72% | — |
| 真白细胞核 S 中位（同图） | 139~159 | — |

误检链条：晚间批 RBC 曝光偏暗/着色偏深（V 中位 171 vs 229）→ 密集叠连处
RBC 局部饱和度升到 60~90（刚过 S_MIN=60）→ 87 万像素过色相门 → 闭运算
连成致密大团（簇内填充率 28~71%）→ 面积/紧凑度全放行 → 出框。
簇合并不拦：RBC 团各自紧致，合并后分件填充率仍达标。

**可分性验证**：窗口内 RBC 像素 S 分布 P75=74 / P90=89（S≥100 仅占全部
RBC 1.02% 且分散），而同图真核 S 中位 139~159——**S_MIN 提到 ~100 可切**，
代价是真核约 25~30% 的低饱和像素流失（核面积 3~5 万 px，余量充足）。
与既有结论一致：**改前须重跑 31 张回归**确认不伤其他批次；RTL 侧更优雅
的替代是帧末"组件平均饱和度门控"（每组件累加 S，一个加法器搞定）。
