## 2. 方法提炼:四段闭环

所有文献共享同一骨架,差异在各段复杂度:

```
帧图像 → [测光] 全帧/中心加权/ROI/分区 → [统计] 均值|加权均值|直方图特征
       → [控制律] 直接方程|变步长粗精调|模糊逻辑 → [执行] I2C 写曝光/增益寄存器
                              ↑__________ 1~2 帧生效延迟(防震荡的根源)__________↓
```

1. **测光**:全帧均值最简;背光场景用分区/加权(复旦:动态分区 + 二维搜索;弹载:高斯权重);高速场景用 ROI 降算力(2017);
2. **统计量**:灰度均值(2024 FPGA)→ 直方图峰值加权均值(2007)→ 直方图特征函数 + 信息熵(2017);
3. **控制律**:①**直接方程**——按 18% 中灰,`新曝光 = 旧曝光 × 目标亮度 ÷ 实测亮度`,线性区一步到位(复旦,最快);②**变步长**——粗调大步长 + 模糊精调(2017);③**过曝状态划分**——大面积饱和时均值已失真,需紧急大步回退(弹载);
4. **防震荡**(共同结论):亮度死区、单次步长限幅、更新周期 ≥ 2 帧、多阈值划分——因为曝光参数写入后 1~2 帧才反映到图像,裸反馈必然来回振。

## 3. 对本项目的适配建议

- **统计硬件复用**:`cvp_awb.v` 已有 32bin×2 组乒乓 Y 直方图 + 帧尾走查(白点门限在用),过曝比例(>250 计数)与均值亮度可直接取自同一套统计,新增逻辑很少;
- **控制节拍**:每 2~4 帧更新一次(匹配 1~2 帧生效延迟),目标亮度 8bit 120(10bit 480),死区 ±5%,单次步长限幅 3×,另加"高光占比 >20% 时强制 0.1× 紧急回退";
- **两段式拆分**:先延长曝光时间至帧率上限(720p60 ≈ 15.7ms),不足再升模拟增益(降低增益会放大噪声,顺序不能反);
- **与 AWB 的耦合**:AE 未收敛时 AWB 统计在漂,建议 AWB 增益更新以"AE 收敛标志"gating,避免双环互拖;
- **显微镜场景备注**:血细胞应用视野是"亮背景 + 暗目标",均值法天然稳定;工业演示若遇逆光,再考虑分区加权。
