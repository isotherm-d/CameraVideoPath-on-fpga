# V25 图像、网口帧边界与白平衡修复

v25 已完成参考照片校准、回归、完整编译和开发板 SRAM 验证。默认曝光 **500 半行**，白平衡参考增益 **R344/G256/B451**，参考曲线锚点 **6500K**。原 v24 Git 标签和比特流保留；本次只下载 SRAM。

## 修复后的行为

1. 跨时钟组缓存的帧首/行尾位按写入格式正确解包：帧首为 bit41，行尾为 bit40。旧版本接反，导致 Bayer 坐标每行重置。真实 FIFO 测试在修复前出现 10 个标记错误，修复后为 0。
2. Bayer 颜色重建使用窗口实际中心的奇偶坐标，修正旧的行列相位猜测与分类错误。真实 FIFO、RAW 齿轮箱和插值流水线的两帧测试，672 个内部像素由全部错误变为全部正确。
3. 两行缓存改为明确的级联同步 RAM 读写，数据、坐标、帧首和 valid 两拍对齐。逐像素验证全部九个邻居、边界、数据间隔和帧首重对齐。
4. 旧坏点判据错误地把红/蓝异色对角像素当作同色邻居。v25 使用四拍原始 RAW 旁路，保留像素坐标和真实颜色；暂不剔除孤立坏点。
5. 四像素组按最早像素在高位打包，符合网口和 DSI 消费顺序，修正每组像素倒序。
6. Q8 增益为 `round(pixel * gain / 256)`，保留溢出后饱和到 255，修正旧的除以 512 和无效饱和判断。
7. 网口一帧为 2,764,800 字节，原 21 位计数器不够。现在按帧大小自动计算位宽，720p 为 22 位。采集必须等待真实帧首，完整帧预算结束后停止到下一帧首；增加 FIFO 读请求保护和字节缓冲预留，避免启动虚拟帧及丢弃预取数据。
8. GUI 直接以 RGB 显示和保存 PNG，显式启用 UDP 广播，显示发送错误，三种白平衡模式明确可用。只发布完整帧，拒绝重复/无效/迟到包；帧率按完整帧计算。
9. 色温换算按实际锚点在倒色温（mired）轴上插值，生成 76 项、100K 一档的 FPGA 表。叠加当前相机的参考校准，预设和参考色温一致；不再使用错误的段索引、有符号插值或固定额外提亮。

## 现在怎样使用

关闭其他收图程序，双击 `tools/打开收图窗口.bat`。

- **标定预设**：使用本次参考校准，初次查看建议选择它。
- **色温 K 值**：拖动色温后自动切换；2500K～10000K，G 固定 256，R/B 按校准曲线换算。
- **手动 RGB**：拖任意 RGB 滑条后自动进入；256=1.0 倍，范围 64～511。
- **R/B 通道互换**：三种模式均生效，正常保持不勾选。
- **曝光**：62～1800 半行，停止拖动 250ms 后下发；500 半行=250 行曝光时间。
- **应用全部参数**：发送当前界面的曝光、白平衡和互换设置。
- `s` 保存当前完整 RGB 帧；`q` 或 Esc 关闭窗口。

GUI 只显示所选参数及发送结果，未实现板端参数回读。“标定预设”采用固定参考增益，不是实时场景 AWB。

| 模式 | 网络命令 | 板端选择 |
|---|---|---|
| 标定预设 | cmd6=1 | 参考曲线锚点 |
| 色温 | cmd7=25..100，cmd6=0 | 色温×100K |
| 手动 RGB | cmd7=0，cmd2/3/4=增益，cmd6=0 | 三通道手动增益 |
| 红蓝互换 | cmd5=0/1 | 所有模式 |

控制包为 8 字节：魔数 C5 A5 50 01、命令 1 字节、数值 3 字节大端。控制端口 UDP6001，图像 UDP6000。

## 参考照片校准

使用用户提供的 IMG_20261007_141523.jpg，将手机照片中白色吸管的 RGB 比例与五张完整单位增益相机帧对应区域比较，得到 R344/G256/B451。选择曝光 500，使参考白色区域处于未饱和范围。

校准时白色参考区的 R/G 比例误差由 25.65% 降到 0.82%，B/G 由 43.28% 降到 1.04%。最后复检在改变后的取景区域测得约 4.58% 和 1.85%；不能把参考区的比例误差当作全图色差或色卡 Delta E。

6500K 是曲线参考锚点，未测量灯光真实色温。本次为单场景外观白平衡；手机图像经过自身成像处理、视角和光照不同，其他光源仍使用近似曲线。低色温需要的蓝增益可能超过硬件范围，此时限幅到 511。

配置在 `tools/wb_profile.json`。修改后运行 `python tools/generate_wb_lut.py`，同步 FPGA 表和顶层默认曝光，再重新编译；`--check` 核对一致性。
