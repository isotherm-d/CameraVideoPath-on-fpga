## 使用(同 NET_操作单)

1. TD 打开 `td_project/camera_to_dsi_display.al`(若曾用 TD 打开过旧版,请先关闭 TD 再打开,
   避免内存态覆写)→ syn_1 Run → 布局布线 → Generate Bitstream → BitWriter 下载;
2. 网线接板上 **ETHA** 座 ↔ 电脑;电脑网卡设静态 IP `192.168.1.100/24`,关防火墙;
3. `cd tools && python eth_video_rx.py --width 1920 --height 1080`(需 numpy + opencv-python 非headless版);
4. 串口 J3 115200-8-N-1 每秒打印 `CAM t=1234567890 f=.. p=.. nz=.. sum=..` 体检行,与网口互不干扰。
