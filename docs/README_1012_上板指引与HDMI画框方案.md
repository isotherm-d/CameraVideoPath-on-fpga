## 1. 框在哪里画的（现状确认）

**现状 = 电脑画**。链路：主板检测出框（det_wbc20）→ det_roi_bridge 转
描述符 → **UDP 6002 状态通道**发描述符（class=0=检出白细胞）→ 同时
**UDP 6000** 发视频帧 → PC GUI（tools/cam_gui_v27.py）收两路，按
frame_id 对齐后**在电脑上把绿框画到画面里**。板子上目前没有任何画框
逻辑，HDMI 子板输出的是无框画面 + 安路 logo。

## 2. 无电脑 HDMI 画框方案分析（最终形态）

**结论架构：主板算框（现状不动），副板画框（HDMI 像素流上叠矩形）。**

关键有利事实（副板文档原文）：*“状态包(6002/fmt=0x26)到达协议栈 UDP
层后被重组器按 fmt 丢弃”* ——说明 6002 框描述符**已经在流向副板的门口**
（ETHB 镜像包含它们），只是被按格式丢弃。改动集中在副板两处：

1. **重组器**：fmt=0x26 分支从"丢弃"改为"识别框包 → 写框 FIFO"
   （框包携带 frame_id，视频包 byte0 也有帧号，可做帧对齐）；
2. **矩形渲染器**（新增，~800-1,500 LUT）：HDMI 75MHz 像素域内，
   每像素对 ≤5 个框做 5 组边界比较，框线上覆写绿色——与 logo OSD
   同款机制（logo 已逐像素 diff=0 验证过）。

主板改动 ≈ 零（待队长确认 ETHB 镜像确实复制 6002）。

**资源预估（副板，v28 实测基数）**：

| 资源 | v28 现状 | +画框后 | 余量 |
|---|---|---|---|
| LUT | 7,556/19,600（38.9%） | ~9,100（46%） | ~10,500 |
| BRAM | 44/64 | ~46（框 FIFO ≈2 块） | ~18 |
| DSP / PLL | 1 / **4 满** | **不变**（渲染器用现有 HDMI 75M 像素时钟） | 28 / 0 |

**已知问题与对策**：①帧同步——框集挂帧号，三缓冲轮换到该帧才生效
（白细胞帧间移动慢，1 帧错位无观感）；②镜像丢包（RGMII 相位漂移已知
问题）——副板保留上一帧有效框集，丢包沿用；③HDMI_OUT 是队长域——
建议分工：我们出框包解析+渲染器 RTL 与仿真，队长做重组器接缝（与主板
detect 协作模式相同）。

**为什么不在主板上画**：主板刚到 85.08%，LeNet 线差 17 片；画框上
主板还要吃 ~1.5k 片并把框"烤进"发给 PC 的像素里。副板画框让主板保持
精瘦，且渲染器投资在"detect 整体搬副板"的远期选项里完整保留。

## 3. 第一阶段上板操作指引（只插主板！副板先不用）

第一阶段目标 = 验证主板跑起来 + 相机出图 + **PC GUI 看框**（框仍由
电脑画）。副板/HDMI 是第二阶段（画框方案落地后）。

### 硬件清单

| 物品 | 接到哪 | 说明 |
|---|---|---|
| 主板 MLKPAI-F02 | 5V DC 供电 | 上电即配置 flash 里旧程序（我们用 JTAG 覆盖） |
| SC500CS 相机模组 | MIPI CSI 座 | I2C=T9/U9、PWDNB=V8（板自动配置相机） |

| PC | 网卡静态 IP 192.168.1.100/24 | tools/打开收图窗口.bat 可自动配置 |

**副板、HDMI 显示器、DSI 7 寸屏：第一阶段全部不需要。**

### 操作步骤

1. **接线**：按上表连接，相机镜头对准显微目镜（或先裸跑看噪声图）；
2. **下载位图**：开 TD 6.2.1 GUI → Tools/下载（Programmer）→ 器件
   PH1P35 → 加载
   `E:\TD_6.2.1\PROJECT\CameraVideoPath-on-fpga\08_csi_dsi_cs500_7cun\syn_1\camera_to_dsi_display.bit`
   （**2026-10-12 13:45 生成，= v29 基座 + detect 全链 ERAM+LUTRAM 版**，
   勿用 v29 发布目录的 bit——那是不含 detect 的基座）→ PROGRAM_SRAM
   方式加载（易失，断电重下；调测期这是优点）；
   ⚠ 若 GUI 里 .al 报 5 个分析错：那是 GUI 开 .al 的已知问题（README_
   1011 §8），下载位图不经过分析，**可忽略**；或在 GUI 开
   syn_1\camera_to_dsi_display.prj；
3. **配网**：双击 `08_csi_dsi_cs500_7cun\tools\打开收图窗口.bat`
   （自动配 PC 网卡 IP）；
4. **看图**：运行 GUI（收 UDP 6000 视频流）——应看到相机实时画面
   720p@30fps；LED/串口有链路诊断输出（v29 起 UDP 状态包覆盖）；
5. **看框**：显微图里有紫染色白细胞时，GUI 按 6002 描述符画绿框
   （**本次上板的核心验证点**——描述符→GUI 画框这条链此前未上过板）；
6. **上板复核项**（README_000 §6.4，发现异常时按此排查）：
   真实相机色相偏移（窗可能偏宽）→ 查 6002 帧的 cid 分布；真实游程
   密度（标签压力）→ giveup 探针；AWB 实际增益 → GUI 画面白平衡。
