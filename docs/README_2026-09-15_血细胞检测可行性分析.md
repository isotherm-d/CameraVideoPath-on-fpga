## 一、可行性实验（用真实血涂片图片实测，非推演）

实验对象：队员上传的一张 386x270 瑞氏染色血涂片照片（内含 6 个白细胞，
约 65 个红细胞，重叠成团）。环境：本机 Python 3.12 + opencv-python-headless
（用户级 pip 安装，不影响工程）。

| 实验 | 结果 | 结论 |
|---|---|---|
| ① 颜色分割 + 白细胞检测 | 白细胞 6/6 全检出、0 误检；白(背景)/粉(红细)/紫(白细) 三色掩码重叠 0 像素 | 紫粉白在色相轴天然分开，det_color_feat 的 HSV 方案对血图成立 |
| ② det_blob3 现架构模拟 | 红/白细胞槽各输出一个 (0,0)-(385,269) 全屏大框 | 同色合并架构与"逐细胞坐标"任务不匹配，必须升级 CCL |
| ③ 红细胞计数三种算法 | Hough 29 / 面积法 43 / 距离变换峰值 57（目视约 65） | 重叠血片上计数精度 ±15~20% 是现实上限 |
| ④ 鲁棒性 | AWB 灰世界 25% 扰动 → 红细胞掩码 -87%~-100%；S_MIN±5 → 掩码 ±22~57%；改 HUE_CB=246°/HUE_BM=316° → 白细胞 96% 归单槽、红细胞 100% 留红槽、漏槽 0 | 检测必须在 AWB 之前；阈值必须运行时可调；白细胞只需改 3 个色相参数（不改 RTL） |

标注图与全部数据：`_blood_test\annotated.png / annotated_rbc.png / run*_out.txt`。

## 二、新需求（仅白细胞 + 移动相机实时框新目标）差距分析

需求拆解：A) 只做白细胞颜色检测；B) 逐细胞出框（不是每色一框）；
C) "新出现"语义（两种解读，见下）；D) 相机移动 = 每帧重检。

| # | 需求项 | 当前状态 | 差距 |
|---|---|---|---|
| 1 | 白细胞颜色分类 | det_color_feat 通用已验证；色相参数需按血图重设 | 改 3 个参数（实验④已验证取值）；另需把阈值从编译期 parameter 改为运行时寄存器（每片染色需重标定）——detect 内小改动 |
| 2 | 逐细胞坐标框 | det_blob3 = 每色一框（实验②证明不够） | 唯一的主体硬件工作：白细胞槽上单遍 CCL（每帧仅 ~6-20 个组件，规模小）；交接文档预留的升级路径，OSD 框接口不变 |
| 3 | 框数量容量 | 集成时 OSD N_BOX=3 | 一屏白细胞可到 10-30 个，建议 N_BOX=8~16；OSD 框层是逐像素组合循环，加框后需重跑 phy_1 看 HDMI 像素域时序 |
| 4 | 检测抽头位置 | 当前接在 AWB 之后（w_awb_*） | 血模式下 AWB 会毁颜色（实验④），需移到 AWB 前（w_pix_*）或加 AWB 旁路——**cvp_top 一行接线，属队长文件，需协调** |
| 5 | "新出现"语义 | 未实现 | 两种解读：①镜头移到哪框到哪（每帧全检，新入画自动获得框，无需跟踪，推荐 demo 用）；②只框/只数"新出现的"（需跨帧跟踪或中线穿越计数器，增量中等）。**需队长拍板** |
| 6 | 实时性 | 特征链 1 像素/拍已验证；720P60@100MHz 预算 1.8 拍/像素 | 颜色路无忧；CCL 单遍流水是标准做法，实时可行 |
| 7 | 验证设施 | 4 个回归 + Python 流式/集成验证 + TD 时序无违例基线（SWNS +0.133） | 全部可复用于 CCL 升级：合成多白细胞帧即可回归 |
| 8 | 图片来源 | 链路只吃 MIPI 相机 | 演示形态待定：相机拍打印片/屏幕/显微镜；手持平移的运动模糊在 60fps 下可忽略 |

**总体完成度估计：约 1/3。** 已就绪：特征提取、OSD 框接口、全部验证方法学、
时序基线、颜色参数取值（实验给出）。缺口主体：CCL（唯一大块硬件）、运行时
调参寄存器、AWB 抽头一行改动（队长文件）、"新出现"语义确定。
