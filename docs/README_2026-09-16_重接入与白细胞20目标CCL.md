## 三、新模块 det_wbc20（白细胞 20 目标 CCL）

替代"每颜色一框"的 det_blob3（同色合并架构无法满足逐细胞框）：

- 单遍 union-find 连通域标记（4-连通），1 像素/拍，行缓存存已解析根
  （根缓存，find 深度 ≤2）；
- live 标签表 32 项寄存器堆 + 帧末 scratch 解析（指针跳跃压平 + 20 轮
  argmax 按面积取前 20），全程与逐像素通路零冲突；
- 输出与 OSD 框接口同格式，框文本 "WBC-01".."WBC-20"，框色亮绿；
- COORD_ADJ 参数兼容两种上游（det_feat_top 窗口路径 =1 /
  det_color_feat 直连 =0，集成用直连以省资源）；
- 解读A（镜头平移每帧全检）由架构自然满足：新进入视野的细胞在下一帧末
  自动获得框，实测**内容帧与框帧为同一显示帧**（零额外显示帧延迟）。
