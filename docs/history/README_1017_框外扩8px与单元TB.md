# README_1017 —— 检测框四边外扩（8px→16px）与 overlay 单元 TB

> 2026-10-17。需求：框稍微大一点，保证白细胞淡染边缘不被截在框外。
> 结论：选固定外扩（零乘法），已实现+单元仿真全绿+联合回归通过；
> 8px 版 0b80a15（gate 77.39%），用户看效果后加到 16px 版 e642e0d
> （gate 77.30%，位图 10-17 20:21）。

## 1. 方案选择：固定 8px 而非等比 1.1×

用户原始想法是 1.1×，明确说"不需要这么精准，本质是想让框大一点，
零乘法也可接受，你来选"。选择**固定外扩 BOX_MARGIN=8px/每边**：

- 淡染色边缘是**绝对宽度**的环（成像模糊+染色梯度，数 px），与细胞
  大小无关——等比放大小细胞只扩 1~2px 不够用，大框又浪费；
- 8 的依据：cid_filter 收缩 ~1px + open3 腐蚀 1~2px + 梯度余量；
- 成本 ~30 slice（纯加法+钳位 mux），等比方案（常数乘）~150 slice；
- 参数化 `parameter BOX_MARGIN = 8`，改 0 即回原行为，板上不满意
  调这一个数即可。

## 2. 实现（cvp_box_overlay.v，+31/−4）

插在**锁存拍**：toggle 窗口内把外扩后的坐标存入 r_b* 寄存器——
逐像素画线通路一行未动，时序零影响（新逻辑每帧只算一次）。

- 外扩+钳位：`x0'=max(0,x0-8)`、`x1'=min(1279,x1+8)`、y 同理
  （12bit 无符号下溢会回卷，钳位必须）；
- **退化框护栏**：全 F 空槽（wbc20 BOX_OFF）/全 0/x1≤x0/y1≤y0 →
  锁存倒置坐标 (4095,4095)-(0,0) 永不命中——顺带消除零框在原点
  的单像素描边（历史遗留小瑕疵）；
- 测试框通路不受影响；线宽 BORDER_T=2px 不变。

## 3. 教训：48bit 框字段序（本轮唯一 bug，两次才改对）

框槽布局 = **x0 在最高 12bit**：`{x0[47:36], y0[35:24], x1[23:12],
y1[11:0]}`。手写下标翻译连错两次（第一次整组反向、第二次 x1/y1
互换），最终改为**槽展开中间变量**一次写对：

```verilog
v_slot = i_box_xy[k1*48 +: 48];
v_x0 = v_slot[47:36]; v_y0 = v_slot[35:24];
v_x1 = v_slot[23:12]; v_y1 = v_slot[11:0];
```

**教训：多字段位切片不要手写偏移，先展开成命名字段再算**——
单元 TB 第一轮就抓出（真框全画不出），否则板上必然翻车。

## 4. tb_box_margin（overlay 首份仿真覆盖）

此前 overlay 只做过板上验证（全屏填充），无仿真断言。新 TB 驱动
整帧 1280×720 流扫描绿色包围盒+像素数，7 检查全过：

| 3 右下角框 | (1270,710)-(1279,719) | 钳位 (1262,702)-(1279,719) |
| 4 全 F 空槽 | 48'hFFF… | 无绿 |

## 7. SW1 按键 = 识别框开关 + 复位写死（2026-10-17 晚，同日第三轮）

**需求链**：队长要"是否开启识别框"开关 → GUI/6001 方案被暂缓，队长点名
SW1 → 引脚核查发现 **SW1(R10) 就是复位键 I_rst_n**（我此前误判"SW1 空闲"，
方案的引脚冲突核查救了一命）→ 队长表态："**不要复位，一复位就死机，
把复位写死，不许复位**" → 死键腾出来做开关，两件事一次改动。

**死机机制（wrapper 实锤）**：按键不直接复位系统，它复位的是 PLL——
`PLL.reset(~I_rst_n)` → PLL 重锁 → `S_pll_lock` 掉低 → `S_rst_n=pll_lock`
全系统复位 → 相机 I2C/UDP 状态重初始化链条断裂 → 死机。
**关键事实：`S_rst_n` 是 PLL lock 不是按键**；上电从不需要按键
（PLL 自锁，FF 初值由位流给出）——写死复位不改变上电行为，只删掉
"把系统按死"这个功能。

**改动清单**（wrapper 4 处 + pin.adc 1 行 + overlay）：
1. `PLL.reset(~I_rst_n)` → `1'b0`；`pll_gmii125.pllreset(~I_rst_n)` → `1'b0`；
2. 顶层端口 `I_rst_n` → `I_sw1_box`（独立端口，不并进队长的 I_button[1:0]）；
3. pin.adc：R10 归属换 `I_sw1_box`（LVCMOS33+PULLUP，格式同按键行）；
4. overlay 加 `i_sw1_n`：2FF 同步 + 20ms 稳定计数防抖（DB_CNT 参数化，
   TB=20 拍快跑）→ 按下沿翻转 `r_box_en`（复位值 1=**上电默认开框**）→
   画线门控 `w_det_hit && r_box_en`——**只停画，检测链照跑**。

**验证**：tb_box_margin 扩到 10 检查（按下消失/再按恢复/亚阈值抖动不
翻转）10/10 PASS；联合回归通过（wrapper 不在联仿 TB 内，链文件零改动）。

**上板验收判据（一幕定乾坤）**：按 SW1 → 框消失**且视频流不断**（同时
实锤"复位已死"+"开关生效"）；再按恢复；SW2/SW3 算法切换不受影响；
断电重启框默认开。

**边界**：现场失去按钮复位手段（本来按了就死机，零损失）；真挂了断电
重启（固化后自动恢复）。SW2/SW3=算法切换（cvp_keys，队长域）勿动。

## 7b. 时序修复：det_wbc20 几何判定拆两级流水（df5ee62，同晚）

SW1 版首综合暴露 **Setup −20ps/TNS −91ps（5 端点）**——重跑一轮结果
**逐位相同**（TD 确定性流程，同输入同布局，重跑无用）。违例全在我们
det_wbc20：帧末 RCM 状态 `w_geom_ok` 同拍算完**两级乘法串联**
（`bw*bh` → 再乘 `COMPACT_PCT`）当 `r_box` 写使能。这条路径前三轮
+144/+104/+17ps 一路收窄——结构性边界路径，加任何逻辑都可能翻负。

**修法**：判定拆两拍——状态16 寄存乘积（`r_barea_r/r_c100_r`）→ 新状态
18 用寄存值判定+写框 → 17 握手不动；空帧/无候选直跳 17 的两条路径零改
动；每簇 +1 拍（帧末余量数百倍），TB 探针同步（w_geom_ok→w_geom_ok_r，
触发态 16→18）。

**验证**：联仿框坐标与改前逐位一致；6 图批量 **18/18 命中零多出**。
**综合**：Setup **+109ps**/Hold +20ps 全正（比修复前所有版本都健康），
gate 16,497=77.76%，位图 10-17 22:04。

**教训**：①TD 确定性——时序坏了改 RTL 或改约束，重跑没用；②边界路径
（余量 <150ps）在多次迭代中迟早翻负，见到就该拆，别赌布局。
