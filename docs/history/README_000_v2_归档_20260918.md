## 5. 帧末簇合并（本阶段核心工作，2026-09-18 完成）

**问题**：分叶核白细胞核叶在二值图上分离（4 连通不桥接细缝），旧版
一细胞出多框或漏检小核叶。

**方案演变（完整记录在 README_2026-09-18 第一、二节）**：
像素闭运算方案被离线实验**否决**（核隙大于可行核尺寸；K≥11 把真细胞
与杂质连成稀疏组件被紧凑度误杀；救不了单件稀疏环核）→ 定案**帧末簇合并**。

**RTL 语义（与 Python 镜像/TB 三方逐项同构，改代码前必读 det_wbc20.v 头注释）**：
- 帧末把 parent/cnt/坐标 拷到 scratch → 压平 → 簇合并 → argmax 取前 10；
- **簇合并**：仅"种子"（像素数 ≥ SEED_MIN）参与；框双向扩 MERGE_GAP 相交
  且并集框 ≤ MERGE_MAXWH 才合并；i 升序发起、j 升序被并入，整表反复扫至稳定；
- **种子-only 是血的教训**：允许吸收碎屑会把边界真细胞的填充率拉低误杀
  （181408 实测 6→4 框）；
- **紧凑度双支路**：整框填充率 **或** 分件填充率（=和/Σ分件框面积）
  ≥ COMPACT_PCT——分件支路救回环形/花斑簇；
- **scratch 七数组必须保持 `(* ram_style = "distributed" *)` LUTRAM 写法**
  （见第 8 节教训 3），COPY/JUMP/BSUM 已串行化，勿退回寄存器堆并行写法；
- 参数（4160 离线口径 ↔ 720p RTL 口径）：GAP 6↔2、SEED 3000↔128（模板
  实验后 cvp_top.v 建议改 256）、MAXWH 400↔128。

## 8. 定量结论（写代码前必读，全是踩过的坑）

1. **宽色相窗 [HUE_CB=700, HUE_BM=900]（246°~316°）保持不变**——收窄会
   漏偏蓝紫的核（180601 实证）；
2. **AWB v2 对检测无害**（S60 时代实测，增益≈1）——检测抽头留在 AWB 后，
   别再提议移到 AWB 前；**但 S100 阈值的 AWB 敏感性未验证**（见第 9 节）；
3. **晚间批 RBC 误检的定量根因**（181033 vs 121635 实测）：两批 RBC 色相
   中位都在窗内（134/145），**判别维度是饱和度**——正常批 RBC S 中位 10
   （窗内占比 1.0%），晚间批 S 中位 33（**窗内占比 14.6%，87 万像素**）；
   真核 S 中位 139~159；**S_MIN 提到 ~100 可切**（S≥100 的 RBC 仅 1.02%）；
4. **分叶核的整框填充率天然 35~45%**（核叶分离+淡染胞质），45% 紧凑度线
   压在其生存边界——S60 掩码胖能过、S100 掩码瘦掉到 37%；
5. **晚间批"单件稀疏漏检"的真因是 RBC 光环稀释填充率**（181747 环核
   34%、182707 大分叶核 34%、模板三个漏检 31/42/27% 全部如此）——
   S100 剥离 RBC 后自然恢复紧致，"单件稀疏"限制大部分随之消失；
6. **簇合并种子-only 语义不可退**：吸收碎屑会稀释填充率误杀真细胞；
7. ModelSim 仿真中 AWB 会 FREEZE（ΣMAD 达不到阈值，增益恒 1）——仿真
   便利性不是 bug；`o_pix_x/y` 比数据早 PIX_LATENCY+1 拍，转储按数据
   节拍自计坐标；
8. **scratch 必须 LUTRAM + 长链必须拆拍**（第 6 节）；91% 利用率=时序崩；
9. Python 镜像与 RTL 的**已知差异**：镜像多 open(3)/close(5) 形态学、
   CCL 用 8 连通（RTL 是 4 连通）——其余语义逐项同构。

## 9. 当前挂起决策（2026-09-19 晚二次更新：重标定修正版已落地）
