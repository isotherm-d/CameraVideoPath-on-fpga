## 三、给队长的三个关键信息

1. **LUT/FF/ERAM/DSP 单看都在 70% 以内，卡死的只有 slice（129%）**。
   原因是装箱：全设计控制集 2,121 个（多时钟域 + 各组寄存器使能/复位
   条件不同），LUT 和 FF 装不进同一个 slice，装箱效率仅 ~51%——
   理想装箱 ~14.1k 片（66%）即可放下，实际摊到 27.4k。
2. **我们已在做的事**：detect 链 93% 的 LUT 集中在 det_wbc20 一个模块
   （live 表 64 项寄存器堆的多读口选择器）。下一步把它迁 LUTRAM +
   NL 64→32，预计 det_wbc20 压到 3~4k LUT，整片回落到 ~105-108%，
   可出位图上板看框。
3. **要到 ≤85%（给 LeNet 分类核留位）需要基座配合**：基座 slice 81.8%
   里，cvp_advanced 占 5,833 LUT（其中显示 style 流 2,721 / frame
   stats 1,895 / contour 969 / median 802）——请队长评估是否有可裁可
   并项；另一个不动功能的杠杆是寄存器使能/复位规整化（控制集纪律），
   对基座装箱效率有直接收益。
