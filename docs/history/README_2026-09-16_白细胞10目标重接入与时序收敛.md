## 三、det_wbc20（白细胞逐目标 CCL）设计要点

- 单遍 union-find 连通域标记（4-连通），1 像素/拍；行缓存存**已解析根**
  （根缓存，父链深度 ≤2，find 只走两级）；
- live 标签表 NL=16（寄存器堆）+ 帧末 scratch 解析（拷贝→3 拍指针跳跃→
  argmax 按面积取前 10），全程与逐像素通路零冲突，约数百拍 < v-blank 74 万拍；
- 帧末"标签表 16 上限 + 输出 10 上限"双重截断，小的落选；
- 输出 OSD 同格式框接口（10 框），文本 "WBC-01".."WBC-10"，框色亮绿；
- 解读A（镜头平移每帧全检）由架构自然满足：新进入细胞下一帧末自动获得框，
  实测内容帧=框帧（零额外显示帧延迟），端到端约 1~2 帧固有（33~50ms）。

## 四、开发中修掉的 4 个 RTL bug（均有 TB 实证）

1. `NLW=7'd128` 溢出为 0 → 分配永远被拒（根源：7bit 装不下 128）；
2. `w_op_al/w_op_mg` 缺 `r_bin1` 门控 → 整幅背景都被"分配"，标签表被垃圾耗尽；
3. 行末断游程写法错误：`w_lf` 在末列被强制清零 → 每行最后一列像素脱离组件
   （框右/下各短 1px、末列竖条被滤）——断行只应清"携带到下一行的游程值"；
4. argmax 末位丢失：当轮最大值恰在扫描最后位置时，同拍提交用了过期 r_best
   ——改为提交 `w_eff_best`（含本拍刷新）。

另修 1 个 TB 场景笔误：帧5 漏填 C 细胞。
