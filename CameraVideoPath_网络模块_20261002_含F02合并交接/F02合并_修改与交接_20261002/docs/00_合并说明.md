日期:2026-10-02

任务:白细胞识别项目——把摄像头图像经底板 ETHA 网口以 UDP 上传上位机实时显示
状态:**已打通**(网口 UDP 收发 100% 无丢包,画面内容为摄像头图像流)

## 一、数据通路

```
SC2336 摄像头 --MIPI CSI--> PH1P35 硬核 DPHY -> RAW10 解包 -> ISP(demosaic+AWB)
  -> AWB 96bit 观测口(本次新增) -> cvp_rgb_stream_pack(新增,单像素化)
  -> cvp_eth_dbg(网络模块,每 2 帧发 1 帧=10fps) -> cvp_gmii_mac_tx -> RGMII
  -> YT8531(ETHA) -> 网线 -> PC(Python eth_video_rx.py, OpenCV 实时显示)
```

UDP 参数:192.168.1.66 → 192.168.1.100:6000,MAC 广播(无 ARP),每包 1440B 像素 + 6B 头,1080p 每帧 4320 包。PC 网卡需设静态 IP 192.168.1.100/24。

## 二、相对原网络模块包(CameraVideoPath_网络模块_20261002)的修改

1. **cvp_gmii_mac_tx.v**:帧内包序计数器 `r_pkt_seq` 由固定 11 位改为 `$clog2(PKTS_PER_FRAME)` 自适应位宽。原包按 720p(1920 包/帧)设计,1080p 为 4320 包/帧,11 位导致帧尾判断永不成立、PC 永远拼不齐帧(现象:心跳正常但 no video stream)。
2. **新增 cvp_rgb_stream_pack.v**:ISP 96bit(4 像素/拍)→ 单像素流转换。内置 96bit×1024 异步 FIFO 吸收行突发 + 预取/展开流水(持续吞吐 1 像素/周期,避免 FIFO 满后按固定节奏丢拍导致画面横向压缩平铺)。
3. **新增 pll_gmii125.v + PH1P_PHY_PLL_WRAPPER_d2616deaaa79.v**:25M→125M GMII 时钟(PLL IP 拷贝自米联客 rgmii 例程)。
4. **isp_top.v**:demosaic/awb 例化参数由 1024×600(旧小屏遗留)改为 1920×1080(行缓冲宽度不匹配会造成整幅行错位);并新增 AWB 96bit 观测输出端口(纯增量)。
5. **时序约束**:网口 125M 时钟加入 SDC 异步时钟组(跨域均走 Gray FIFO/双拍同步)。
6. **i_dbg_flags** 接真实诊断(相机 I2C 配置完成/AWB 观测口有数据/转换器发像素/像素非全零),心跳状态页可在 PC 端远程查看。

## 三、引脚约束(依据官方《04_以太网管脚定义表-J1.xlsx》,与 05_rgmii_loop 例程交叉验证一致)

TXD0~3 = P3/R1/R2/U1,TXCTL = L2,TXCK = R3(LVCMOS33,DR16,FAST,OUTDEL=3),MDC = M5,MDIO = V1,PHY 复位 = H2(恒高)。⚠ 注意:`E:\TD_6.2.1\PROJECT\CameraVideoPath\constraints\pin.adc` 是旧板 HX1P35B(带 HDMI)的约束,不可参考。

## 四、串口体检功能(保留)

工程同时保留 UART 摄像头体检:J3 脚 115200 每秒打印
`CAM t=1234567890 f=<帧率> p=<有效拍> nz=<非零拍> sum=<亮度总>`,
t=1234567890 为自检值。用于无屏判断摄像头状态(f≈20 为正常)。

## 六、复现步骤

1. TD 打开 `camera_to_dsi_display.al`(或在自己工程中加入 01 的 7 个 RTL + 02 的改动文件);
2. 综合 → 布局布线 → 生成位流,BitWriter 下载;
3. 网线连 ETHA ↔ 电脑,电脑设 192.168.1.100/24,关防火墙;
4. `python eth_video_rx.py --width 1920 --height 1080`。

## 七、遗留事项

- 图像颜色通道序(R/B)未与标准色卡核对,若上游算法需要可一行修正;
- 当前为调试帧率 10fps,如需更高可将 cvp_eth_dbg 的 FRAME_SKIP 改 1(全速 ~20fps,千兆内);
- GEN_TESTPAT=1 可切内置彩条(不依赖相机),用于网口链路自检。
