# 上电默认自动曝光及标定白平衡

复位后自动曝光开启；白平衡使用标定预设，R/G/B增益Q8为344/256/451。上位机初始自动曝光复选框同步勾选。图像模式默认为原图0。

保留五位延迟、两位空白、最右模式的布局，KEY3递增、KEY2递减。与上一部署版相比，硬件仅修改配置控制器中自动曝光的有效值和待提交值两个复位位。

位流：`physical/camera_to_dsi_display.bit`，用于PH1P35MDG324主板。SHA256：`6ada7f0de86068ef30e96131a28916a69cb85b6c8da81277475e9fbb4f9638c1`。

完整实现：Slice 19561/21216，ERAM 94/108，DSP 35/40；setup +0.003 ns，hold +0.020 ns。

43项视频RTL回归、两项网络包校验和39项Python测试通过。配置测试检查初始值、读回、运行时改为手动/自动场景后再次复位的默认恢复；460帧曝光闭环测试不发送主机配置指令，覆盖暗、极暗和亮场景。

已完成主板SRAM验证、启动SPI Flash烧写及回读校验，实际部署情况以summary.json和programming/记录为准。物理断电再上电尚未验收。
