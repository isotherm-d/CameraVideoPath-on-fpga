# 主板数码管延迟显示候选位流

8位数码管显示采集首组RAW10到同帧视频最后一包发送完成的延迟，单位ms、三位小数，每200 ms最多更新一次，超过1秒无测量显示横线。

物理实现：19554/21216 Slice，94/108 ERAM，35/40 DSP；setup +0.101 ns，hold +0.021 ns。42项视频RTL、两项包完整性、39项Python测试及计时/数码管专项测试通过。

位流：`physical/camera_to_dsi_display.bit`。功能说明见 `docs/mainboard/数码管延迟显示.md`。

当前JTAG读到EG4D20EG176显示子板，未执行任何下载。此位流仅用于PH1P35MDG324主板；数码管实物显示尚待验收。原模型和旧版本位流保留。
