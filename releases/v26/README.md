# V26 发布

1280×720@30fps；原图、灰度、二值化、边缘、卡通、素描、复古暖色；自动曝光、自动白平衡、可选自动色阶；帧身份及延迟显示；统一分类挂接接口。基于 v25，旧版本和标签保留。

实物连续运行 1800.6 秒，接收 53953 帧，平均 29.964fps，累计完整率 100.000%。期间每秒检查状态新鲜度、视频流错误和 I2C 错误。完整记录见 hardware_validation.json。布线 setup WNS=0.109ns、hold WNS=0.020ns，setup/hold TNS=0。

## 使用

1. 网卡设 192.168.1.100/24，连接板端网线与供电。
2. TD 选择 PROGRAM_SRAM，加载 camera_to_dsi_display_v26.bit，下载成功后短按 SW1。
3. 双击 ../../08_csi_dsi_cs500_7cun/tools/打开收图窗口.bat。旧 cam_gui.py 用于旧版本，新版本是 cam_gui_v26.py。6000 收图、6001 控制、6002 状态；不要同时打开两个收图程序。
4. 恢复 v25 时，按相同方式加载 ../v25/camera_to_dsi_display_v25.bit。SRAM 程序断电丢失。

接口与测量口径见 ../../08_csi_dsi_cs500_7cun/V26开发与接口说明.md，队友接线片段见 ../../08_csi_dsi_cs500_7cun/V26队友挂接示例.md。

## 验证边界

- 七种模式、手动增益、AE/AWB 与自动色阶在当前一个实物场景检查；30分钟稳定性测试使用恢复后的原图/手动曝光/标定白平衡设置。它不等于每种自动模式各连续运行30分钟。
- 两种光源的白平衡精度、明暗变化后的 AE 收敛时间、实体功能键操作尚未完成专门实测；相关控制器已有仿真覆盖。
- 分类接口经过合成数据及反压验证；真实 ROI 算法、LeNet 核心和权重由队友挂接。
- DSI/HDMI 和真实光学显示延迟未验收。GUI 显示的是 FPGA、PC 分段时间及带误差的显示提交估计。
- Slice15410/21216（72.63%）超过原方案尽量70%的软预算，ERAM54/108、DSP10/40。挂接模型后必须重新评估资源和时序。
- SRAM 热重载后需要 SW1 复位，启动 I2C 错误保持真实上报。

比特流和记录的 SHA256 见 manifest.json。目录不包含个人场景照片。
