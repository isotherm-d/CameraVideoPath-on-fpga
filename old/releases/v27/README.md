# V27 发布

1280×720@30fps。边缘/素描独立高低阈值与线宽；更完整的弱轮廓；以标定预设为先验的保守 AWB；中文覆盖文字与分类 I2C 诊断；摄像头启动等待、重试和第一完整帧门控。原图标定 R344/G256/B451 和统一分类挂接接口保留。

## 使用

板子当前已加载此版本。双击 ../../hardware/mainboard/tools/打开收图窗口.bat。选择“边缘”或“素描”后，右侧向下滚动查看轮廓控件。边缘推荐低45/高90，素描低50/高100；主阈值越低，细节越多。低阈值默认联动一半，可取消后独立输入；两模式各自记忆，复位后恢复默认。需要更明显轮廓时可尝试主阈值60，并按场景调整。

完整操作和接口见 ../../hardware/mainboard/V27优化与阈值说明.md。收图UDP6000、控制6001、状态6002，只打开一个收图程序。SRAM断电丢失，重新上板使用 PROGRAM_SRAM 加载 camera_to_dsi_display_v27.bit。

恢复v26：下载 ../v26/camera_to_dsi_display_v26.bit，短按SW1，并打开 ../../hardware/mainboard/tools/打开v26收图窗口.bat。v26标签和发布文件完整保留。

## 实际验收

- 6项新RTL、12项v26 RTL、10项基线RTL、35项Python测试通过；基础/扩展状态包CRC、IPv4校验和、UDP端口检查通过；隐藏模拟GUI及真实板端GUI检查通过。
- 未按SW1的热重载连续验证两次，初始化错误0、重试0；当前 I2C 写入正常。没有执行断电后从 Flash 启动v27的验收，也没有改写Flash。
- 七模式每约10秒轮换，AE/AWB开启，持续 300.2 秒、8996 帧，平均 29.965fps，完整率 100.000%，无报告的视频流/I2C错误。
- 固定场景验证阈值响应、加粗、独立参数和自动白平衡；自动增益最终344/256/451，与标定预设一致。该结果属于一个桌面场景，不等同两光源/色卡精度认证。
- 布线setup WNS=0.107ns、hold WNS=0.020ns，TNS均为0。
- Slice 17359/21216（81.82%）、ERAM66/108、DSP10/40。剩余逻辑空间较v26缩小，接入真实模型后必须重新评估资源和时序，不能保证仅凭剩余数量即可放入LeNet。

真实ROI/LeNet核心、实体模式键专项操作、DSI/HDMI与光学延迟不在本轮实物验收记录内。源码与像素接口已保留挂接条件。

文件校验见manifest.json：.bit为原始字节SHA256，文字先将CRLF转换为LF后校验。发布目录不包含个人场景照片。
