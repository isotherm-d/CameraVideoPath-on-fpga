## 改动

1. `cvp_fx_median` 增加 CHANNEL_BITS 参数，默认 8 保留原通用接口；卡通风格使用 3。输出仍为 RGB888，所选高位保留、低位补零，后续按原公式扩展三位颜色。min/max 网络与单调量化可交换，卡通有效像素保持一致。TD 进一步删除了邻域中不再使用的低位数据，风格窗口 ERAM 12→10。
2. `cvp_tone` 将常数分子 57344 的除法和限幅改为精确常量查表。保留原 start/busy/done 节奏、40 次迭代的等长等待，以及 SOF 更新系数的时刻；保持忙时重复请求和完成拍碰撞行为。RGB 数据通路、offset 舍入及低跨度旁路不变，表没有额外占用 ERAM。
3. 修复 GUI 源码列表丢失 `cvp_dpc.v` 后产生黑盒的错误：把主路径一直使用的 BYPASS=1 四拍 RAW 延迟内置到 `cvp_proc.v`，保持每拍 RAW、valid、SOF、异步复位行为。独立 DPC 文件仍保留作旧检测器回归，主路径不再依赖它的注册。构建模板也移除这一非必需依赖。

## 验证

27 项 RTL 测试及两组独立线上包 CRC/IP/UDP 校验全部通过。包含原有 22 项、四项新增 v30 冻结基准差分，以及 RAW→demosaic 全边界集成测试。

- 中值：100000 组激励，87455 个有效样本；覆盖量化边界、同箱不同低位、随机数据、valid 空洞和多次复位。3 位输出的最终量化值与旧版一致，默认 8 位实例全 RGB 与旧版一致。
- 风格：预热后逐拍比较 14 帧、129184 个输出样本，保证七模式各覆盖两帧；比较 RGB、坐标、帧号、配置号、SOF/EOL/EOF、OSD/AE/WB 元数据、valid 与 overflow。
- 对比度：全部 65536 个 black/white 输入组合、3018787 个比较周期；还包括 4096 拍忙时请求、任意 SOF/使能和计算中复位激励。全部输出周期与 pending/active 系数逐拍一致。
- RAW 旁路：与板测 v30 的 `cvp_proc + cvp_dpc.BYPASS=1` 逐拍比较 38064 拍、14717 个有效像素；所有输出以及内部 RAW、valid、SOF 一致，覆盖七种模式、帧重启、valid 空洞和异步复位。
- 新旧基准冻结在 `tools/sim/gold_v30/`；恢复原模块名后的源码 SHA256 与 v30 manifest 一致，避免用新实现充当参考。
- 同一 TD 6.2.168116、PH1P35MDG324 完成综合、布局布线和比特流生成，当前 RTL 与实际构建快照匹配。
